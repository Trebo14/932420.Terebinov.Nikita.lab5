# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №5.

## Что реализовано
- **Поиск элементов**: использованы методы `getElementById`, `querySelector` и `querySelectorAll`:
  - `getElementById` — для кнопки темы, формы трека, полей ввода, контейнера плейлиста и кнопки очистки;
  - `querySelector` — для кнопки скрытия плейлиста и самого блока плейлиста;
  - `querySelectorAll` — для получения всех полей формы трека, их проверки и последующей очистки после добавления трека.
- **Манипуляции с DOM**:
  - динамическое создание элементов (`document.createElement`) для добавления треков в плейлист;
  - удаление элементов через очистку контейнера (`innerHTML = ""`) и фильтрацию массива данных;
  - изменение атрибутов и классов: `type`, `checked`, `className`, `classList.toggle`, `classList.add`, `classList.contains`.
- **Интерактивность**:
  - добавление трека с названием и длительностью через форму без перезагрузки страницы (`event.preventDefault`);
  - удаление конкретного трека кнопкой «Удалить»;
  - полная очистка плейлиста кнопкой «Очистить плейлист» с подтверждением через `confirm`;
  - добавление трека в «Избранное» через чекбокс с текстовой подписью `label`;
  - переключение светлой/тёмной темы;
  - скрытие/показ блока с плейлистом.
- **Обработка ошибок**:
  - проверка существования всех необходимых DOM-элементов перед началом работы;
  - использование `try...catch` при чтении JSON из `localStorage`;
  - проверка `Array.isArray` при восстановлении плейлиста - если данные не являются массивом, состояние сбрасывается;
  - валидация пустых полей ввода через `trim()`.
- **Сохранение состояния (`localStorage`)**:
  - сохранение и восстановление выбранной темы оформления;
  - сохранение и восстановление списка треков, включая флаг «Избранное»;
  - сохранение и восстановление состояния видимости плейлиста (скрыт/показан).
