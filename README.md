# Музыкант и звукорежиссёр о себе
Учебная лабораторная работа №5.

## Что реализовано
- **Поиск элементов**: Использованы методы `getElementById`, `querySelector` и `querySelectorAll` для получения доступа к элементам страницы.
- **Манипуляции с DOM**: 
  - Динамическое создание элементов (`document.createElement`) для добавления треков.
  - Удаление элементов (`innerHTML = ""` и фильтрация массива).
  - Изменение атрибутов (чекбоксы, классы).
- **Интерактивность**:
  - Добавление трека (название и длительность) через форму без перезагрузки страницы (`event.preventDefault`).
  - Удаление конкретного трека или полная очистка плейлиста (с подтверждением `confirm`).
  - Добавление трека в «Избранное» (чекбокс).
  - Переключение светлой/тёмной темы.
  - Скрытие/показ блока с плейлистом.
- **Обработка ошибок**: 
  - Проверка существования всех DOM-элементов перед началом работы.
  - Использование `try...catch` при чтении JSON из `localStorage` (защита от поврежденных данных).
  - Валидация пустых полей ввода (метод `trim`).
- **Сохранение состояния (localStorage)**:
  - Сохранение и восстановление темы оформления.
  - Сохранение и восстановление списка треков (с флагом «Избранное»).
  - Сохранение состояния видимости плейлиста (скрыт/показан).
